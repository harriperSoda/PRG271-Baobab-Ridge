# PRG271 Baobab Ridge

C# Windows Forms group project for the Baobab Ridge Wildlife Rehabilitation Records System.

## Student Numbers

- Mickayla Samuel - 604505 - Components 4 and 5: Add Animal and Search / Edit / Update

## Component Notes

**Component 4 - Add Animal (Mickayla Samuel)**
Reads the form input, validates it, checks for a duplicate ID, classifies the recovery score, creates the Animal, appends exactly one new line to animals.txt, refreshes the grid and clears the form.

**Component 5 - Search / Edit / Update (Mickayla Samuel)**
Loads an animal by clicking a grid row or searching by ID and enters Edit Mode (the ID is locked). On update it validates the changes, re-runs the classification, rewrites animals.txt so only that record changes, refreshes the grid and returns to Add Mode.
